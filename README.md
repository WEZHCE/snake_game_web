## 🐞 相对原版的修复与优化

1. **每日挑战完整可玩**：原版定义了挑战状态机与「挑战」翻译，但没有入口按钮也无法进入游玩；本版实现完整规则、结算界面、XP 奖励与每日最佳纪录。
2. **双头蛇皮肤「空格反转方向」从未实现**：原版 SPACE 被暂停占用；本版装备该皮肤（特效开启）时空格反转蛇身，暂停改用 P 键或画面按钮。
3. **熵减蛇成就「倒行逆施」永远无法解锁**：原版 `game_completed` 恒为 False。
4. **自然死亡不结算**：原版只有点击「结束」按钮才检查成就、发放 XP 与累计食物数；本版两条路径统一结算。
5. **皮肤商店点击判定错位**：原版绘制行高 90px、点击判定却按 120px / 偏移 64px 计算，导致点错皮肤；本版统一几何。
6. **「新纪录」每局必现**：原版在最高分更新之后才比较；本版先比较后更新。
7. **连胜不重置**：原版对战失败/平局仍累加连胜；本版失败重置。
8. **主题弹窗高亮与实际配色不一致**：原版启动时使用 Colors 类默认配色却高亮 nord 主题；本版将初始配色固化为隐藏主题并正确高亮。
9. **对战开局未重置计时**：上一局的时长会带入对战中。
10. **输入队列可致 180° 自杀**：快速连按两个相反方向经队列执行后撞颈死亡；出队时二次校验。
11. **段位面板里程碑溢出被截断**：钻石/大师两项超出面板不可达；本版支持滚动查看。
12. **代码结构**：4490 行单文件拆分为 9 个职责单一的 ES Module，弹窗滚动统一抽象，事件路由集中管理。

## 🎮 操作

| 按键 | 功能 |
|------|------|
| 方向键 / WASD | 控制蛇移动 |
| 空格 | 暂停/继续（装备双头蛇皮肤时为反转方向） |
| P | 暂停/继续 |
| ESC | 返回菜单 |
| + / - | 菜单中调节音量 |

## 🚀 本地运行

纯静态站点，任选其一：

```bash
# 直接双击 index.html（需支持 ES Module 的现代浏览器，推荐本地服务器）
# 或
python -m http.server 8000
# 或
npx serve .
```

浏览器打开 http://localhost:8000 即可。

## 📁 项目结构

```
snake_game_web/
├── index.html          # 入口页面（880×720 画布，自适应缩放）
├── css/style.css       # 页面外壳样式
└── js/
    ├── main.js         # 状态机 / 输入 / 主循环 / 结算
    ├── ui.js           # 全部界面绘制（1:1 复刻）
    ├── game.js         # 单人核心逻辑 + 每日挑战规则
    ├── vs.js           # 人机对战（BFS AI ×3 难度）
    ├── data.js         # 主题 / 皮肤 / 成就 / 规则等静态数据
    ├── i18n.js         # 中 / 英 / 日三语文本
    ├── state.js        # 全局运行时状态 + 段位/XP
    ├── audio.js        # Web Audio 程序化芯片音乐
    └── save.js         # localStorage 存档（双 Key 备份）
```
